# ULTRON — Sovereign Local AI Assistant & Laboratory

> **ULTRON** is a fully functional, offline-capable local AI system featuring a custom-trained Byte-Level BPE Transformer laboratory, unconstrained multi-turn general chat, and document-grounded semantic Retrieval-Augmented Generation (RAG) powered by dense sentence embeddings and local Llama 3 inference.

---

## 1. Project Introduction

ULTRON was developed to bridge the gap between educational, from-scratch deep learning models and practical, production-grade local AI assistants. Running entirely on local hardware, ULTRON maintains complete data privacy by eliminating external cloud API dependencies.

The application serves two complementary functions:
1. **Practical AI Assistant**: A dual-mode assistant offering **General Conversational AI** and **Document-Grounded Knowledge Assistant (Semantic RAG)** with conversation-aware follow-up resolution and hierarchical full-document summarization.
2. **PyTorch Research Laboratory**: Interactive experimentation and inference with custom frozen Transformer models:
   - **Ultron v0.1**: A character-level Transformer built from foundational PyTorch blocks.
   - **Ultron v0.2**: A 1,323,728-parameter 4-layer Transformer trained on the TinyStories dataset with a custom Byte-Level BPE tokenizer.

## 2. Key Features

- **Dual-Mode Chat Architecture**:
  - **General Chat Mode**: Unconstrained conversation, technical explanations, coding help, and reasoning powered directly by local `llama3:latest` through Ollama.
  - **Document RAG Mode**: Strict grounded answering based exclusively on uploaded files, complete with source citations, page references, and cosine similarity scores.
- **Real-Time Token Streaming & Generation Controls**:
  - Full end-to-end Server-Sent Events (SSE) streaming delivering decoded tokens immediately as they are generated by Llama 3 (sub-500ms Time-to-First-Token in RAG mode).
  - Interactive "Stop" button in the chat interface allowing users to abort running inference on demand.
  - Persistent HTTP connection pooling (`requests.Session`) and configurable 15-minute VRAM `keep_alive` caching.
  - One-click GPU VRAM release in the Settings modal (`/api/model/unload`).
- **Multi-Format Document Ingestion**:
  - Parses `.txt`, `.md`, `.pdf` (with page-level tracking), and Word `.docx` documents.
  - Automatic duplicate detection using SHA-256 content hashing prevents redundant vector generation and index bloat.
  - Graceful handling of empty, corrupted, and scanned documents with clear OCR guidance.
- **Dense Semantic Embeddings & Lightweight Hybrid Search**:
  - Uses `sentence-transformers/all-MiniLM-L6-v2` generating 384-dimensional dense vectors with CUDA acceleration (NVIDIA RTX 3050).
  - High-performance, zero-external-dependency vector storage backed by in-memory NumPy matrices and disk persistence (`embeddings.npy` and `metadata.json`).
  - Lightweight hybrid ranking combining dense cosine similarity with lexical keyword overlap to ensure precise retrieval for exact names, metrics, and technical terms.
- **Complete-Document Hierarchical Summarization**:
  - Dedicated map-reduce summarization pipeline for long documents.
  - Divides documents into logical sections, generates intermediate summaries, and synthesizes a cohesive final document summary without repetition.
  - Supports `Detailed`, `Executive Short`, and `Key Points` summary styles.
- **Conversation-Aware Retrieval (Follow-Up Resolution)**:
  - Resolves ambiguous pronouns and relative references (e.g., *"When was he born?"*, *"Does it use a GPU?"*) into standalone search queries based on recent dialogue history.
- **SQLite Persistence Layer**:
  - Conversations, messages, document registry, and application settings persist across server restarts in `rag/index/ultron.db`.
- **Claymorphic 3D UI**:
  - Modern claymorphism interface with collapsible sidebar, conversation list, markdown rendering with code block highlighting and copy buttons, source inspection cards, and system status telemetry.

## 6. Installation & Environment Setup

### Prerequisites
- Windows 10/11 (x64)
- Python 3.10 to 3.13
- NVIDIA GPU with CUDA support (e.g., RTX 3050 Laptop GPU, 4GB VRAM) or CPU fallback
- [Ollama](https://ollama.com/) installed on your machine

### 1. Set Up Python Environment
Ensure you are using the dedicated virtual environment:
```powershell
# Navigate to the project root
cd "C:\Users\rohit\Downloads\ALL projects\Ultron"

# Verify virtual environment Python
.\.venv\Scripts\python.exe --version
```

### 2. Install Dependencies
```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. Install Ollama & Download Llama 3
1. Download and install Ollama from [https://ollama.com](https://ollama.com).
2. Start the Ollama server:
   ```powershell
   ollama serve
   ```
3. In a separate terminal, pull the default Llama 3 model:
   ```powershell
   ollama pull llama3:latest
   ```
4. Verify the model is present:
   ```powershell
   ollama list
   ```

## 7. How to Launch and Use ULTRON

### Launching the Application
You can use the one-click Windows launcher or execute directly with Python:
```powershell
# Method A: One-click launcher
.\run.bat

# Method B: Direct command from project root
.\.venv\Scripts\python.exe ui/app.py
```
Open your web browser and navigate to:
```
http://127.0.0.1:5000
```

### Using General Chat Mode
1. Click **+ New Chat** in the sidebar.
2. Select **General Chat** in the mode toggle.
3. Type any general knowledge question, coding prompt, or request (e.g., *"Write a Python script to sort a list of dicts"*).
4. Ultron generates answers directly using `llama3:latest` without searching documents.

### Using Document RAG Mode
1. Ensure **Document RAG** mode is selected.
2. Under the **Upload Document** panel on the right, drop or select a `.txt`, `.md`, `.pdf`, or `.docx` file.
3. Click **Index into Knowledge Base**. Ultron will extract text, generate 500-char overlapping chunks, compute 384-d embeddings using your GPU, and save the vectors to disk.
4. Ask any question about your document (e.g., *"What is discussed on Page 3?"*).
5. Ultron returns a grounded response with source inspection cards detailing document names, page numbers, and similarity scores.

### Using Long-Document Summarization
1. In the **Knowledge Base** panel, locate any indexed document.
2. Click the **Summarize** button next to the document.
3. Choose your preferred depth:
   - **Detailed**: Multi-section comprehensive synthesis.
   - **Executive Short**: 2-3 paragraph core summary.
   - **Key Points**: Bullet points of critical takeaways and names.
4. Click **Generate Complete Summary**. The hierarchical summarizer will process all sections and display the synthesis with a one-click copy button.

## 10. Privacy & Local Operation

All operations in ULTRON are strictly local:
- No telemetry, documents, queries, or chat messages are transmitted to any cloud or third-party server.
- Embeddings are generated locally using `sentence-transformers`.
- Text generation is performed on the local Ollama instance at `http://127.0.0.1:11434`.
- All persistent data remains stored in local project folders (`rag/index/` and `rag/uploads/`).

## 11. Known Limitations

- **Single-User Local Architecture**: Designed for personal local operation rather than multi-tenant concurrent production deployments.
- **Scanned PDF Optical Character Recognition**: Text extraction from PDFs relies on embedded text layers; image-only scanned documents require external OCR preprocessing before upload.
- **Ollama Dependency for Generation**: Ingestion, chunking, embedding, vector storage, and semantic retrieval operate completely independently of Ollama; however, natural language answer generation requires an active Ollama instance.
