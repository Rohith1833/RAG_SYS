# Ultron v0.2 Baseline

## Purpose

Ultron v0.2 is the first Ultron model trained on a real text dataset using a custom Byte-Level BPE tokenizer.

## Dataset

Dataset: TinyStories

Stories used: 10,000

Training tokens: 2,175,833

Validation tokens: 241,760

## Tokenizer

Tokenizer: Byte-Level BPE

Vocabulary size: 2,000

Special tokens:
- <unk>
- <bos>
- <eos>

Tokenizer file:

data/real/tokenizer.json

## Model

Model: UltronV2

Parameters: 1,323,728

Embedding dimension: 128

Attention heads: 4

Transformer layers: 4

Context length: 128

## Training

Batch size: 16

Learning rate: 0.0003

Training steps: 5,000

## Hardware

GPU: NVIDIA GeForce RTX 3050 Laptop GPU

VRAM: 4 GB

CUDA: Enabled

## Checkpoint

checkpoints/ultron_v2_checkpoint.pt

## Status

Ultron v0.2 is complete and serves as the baseline for future experiments.

Do not modify the v0.2 checkpoint or v0.1 files while developing future versions.
